# Sovereign On-Premise AI Workbench: Interactive Prototype

A single-page prototype of Phases 0-7. It runs entirely in the browser with no backend.
All outputs (network checks, sandbox runs, audit chain) are simulated.

## Run locally
Open `index.html` in a browser.

## Deploy
Hosted on Netlify (see `netlify.toml`). Publish directory is the repo root.
